# Reproduce the bounded FGFR2 sequence pilot

Run from the Escape Lab project directory. The project dependencies and old pilot
code remain frozen. Torch and Transformers use a separate `uv` overlay rather
than modifying `pyproject.toml`, `uv.lock`, or the project environment.

```sh
HF_HUB_DISABLE_XET=1 TOKENIZERS_PARALLELISM=false uv run --frozen \
  --with 'torch==2.8.0' --with 'transformers==4.57.1' \
  python -m escape_lab.fgfr2_sequence_features \
  --candidates research/fgfr2-sequence-pilot/feature-candidates.json \
  --references data/revision-v2/features/references.json \
  --output data/fgfr2-sequence-pilot/esm2-35m-v1 \
  --device mps --batch-size 4
```

The supplied candidate file contains only the 668 previously complete, eligible
FGFR2 development variants. It was generated by `feature_candidates` in
`escape_lab.fgfr2_sequence_run`, which reconstructs the original exclusions and
checks the old cohort. The extractor independently checks protein identity,
reference sequence, residue indexing, and original development/validation status.
Use `--device cpu` on machines without Apple GPU support and record that different
runtime in a new feature cache. Never overwrite an existing cache or experiment.

```sh
uv run --frozen python -m escape_lab.fgfr2_sequence_run \
  --features data/fgfr2-sequence-pilot/esm2-35m-v1 \
  --output reports/mechanistic-pilot/fgfr2-sequence-v1
```

Use a new output directory for a deliberate rerun. The runner writes and hashes
its protocol before ingesting activation targets or fitting heads. It checks all
protected artifacts before and after scoring. A run does not modify old pilot
code, predictions, external assay datasets, or the original final split.

`research-and-protocol.md` specifies the four arms, strict primary and secondary
endpoints, original global fold mapping, and advancement criteria. The prior
all-gene regression is a cached reference; the three new heads are FGFR2-only.
External assay outcomes and resistance labels are not used by this experiment.

The feature cache records the exact ESM2 checkpoint revision, weight checksum,
full reference sequence checksum, packages, device, batch size and extraction
time. The checkpoint is an unsupervised protein sequence model. No assay labels
are supplied to it; no large-model fine-tuning or paid LLM inference occurs.
