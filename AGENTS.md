# Escape Lab implementation agreements

Scope all edits to this directory. The parent repository has unrelated user work;
do not switch its branch, stage its files, or revert any changes.

The product replays published preclinical assays. It does not simulate patient
outcomes, recommend treatments, or validate drug combinations or sequences.

Keep raw outcomes outside agent prompts and tool access except authorized reveals.
Keep all representations of a protein variant and aligned positions grouped.
The final split is sealed until the policy and acceptance rules are frozen.
Do not run final evaluation during development or inspect its detailed outcomes.

Never print credentials or add .env, databases, or hidden outcomes to Git.
Use .venv Python through uv. Write meaningful tests before consequential code.
Changes to labels, budgets, splits, metrics, and access are evaluator-owned.
Record attempted revisions, including rejected ones. Report failures honestly.
